A visually stunning, high-performance web application that delivers real-time weather tracking through a sleek **Glassmorphism UI**. Designed with interactive visual feedback, dynamic condition-based background video switching, and custom rainy glass-pane effects.

---

## ✨ Key Features

* **Real-time Atmospheric Data:** Fetches instant, accurate weather metrics including live temperature, condition descriptions, humidity levels, and wind speed.
* **Dynamic Video Backgrounds:** Contextually renders distinct high-definition background videos (`rain.mp4`, `clear.mp4`) based on real-time API response parameters.
* **Custom Glassmorphism & Water Droplet Overlay:** Features a frosted glass UI component rendered using backdrop blurs and a custom multi-layered radial gradient droplet texture.
* **Fully Mobile Responsive Layout:** Built with dynamic viewports and media query overrides for smooth cross-device rendering (Desktop, Tablet, Mobile).
* **Interactive UI Animations:** Smooth hover transitions, floating weather icons, and continuous fluid gradient shifts for enhanced UX.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React.js (Bootstrapped with Vite for fast HMR)
* **API Integration:** OpenWeatherMap REST API via Axios
* **Styling & Effects:** Custom Pure CSS3 (Backdrop Filters, Keyframe Animations, Flexbox, Media Queries)
* **Version Control:** Git & GitHub
